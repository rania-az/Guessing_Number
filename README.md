# Guessing Number
A simple number guessing game developed in C as a beginner programming project.

## Description
The computer generates a random number between 1 and 10. The user tries to guess the secret number.
The program provides feedback to help the user find the correct number.

## Features
- Random number generation
- User input through the console
- Feedback when the guess is too high or too low
- Unlimited guessing attempts
- Attempts counter

## Technologies
- C Programming Language
- Code::Blocks IDE

## Concepts Practiced
- Variables and data types
- `printf()` and `scanf()`
- Conditional statements (`if`, `else`)
- `while` loops
- Random number generation (`rand()`, `srand()`)
- Increment operator (`++`)

## How to Run
1. Open the project in Code::Blocks.
2. Build the project.
3. Run the program.
4. Enter a number between 1 and 10.
5. Keep guessing until you find the secret number.
